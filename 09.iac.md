# IaC - Infrastructure as Code


## Definition

### Infrastructure as Code

from wikipedia:
IaC is the process/practice of managing and provisioning computer resources through machine-readable definition files

from "Infrastructure as Code, Patterns and Practices", by Rosemary Wang:
Infrastructure as code (IaC) applies DevOps practices to automating infrastructure changes in a codified manner to achieve scalability, resiliency, and security.
 
### Infrastructure

Today, with so many services, we cannot describe infrastructure with just compute, network, and storage categories: you can’t limit the definition of infrastructure to hardware or physical devices.

**Infrastructure** refers to the software, platform, or hardware that delivers or deploys applications to production.


## IaC tools

IaC tools categories: 
- **Ad hoc scripts**
- **Configuration management tools**: ensure that servers and computer systems run in the desired state
- **Server templating tools**: instead of launching a bunch of servers and configuring them by running the same code on each one, you create an image of a server that captures a fully self-contained “snapshot” of the operating system (OS), the software, the files, and all other relevant details. Ex: Docker, Packer, and Vagrant.
- **Some Orchestration tools**
- **Provisioning tools**: let to provision (deploy and manage) infrastructure. Ex: terraform, CloudFormation, Pulumi, ...


## Principles of IaC

- Reproducibility
- Idempotency
- Composability
- Evolvability
