# Some Useful Commands

## status

```bash
kubectl version
kubectl get nodes
kubectl cluster-info

```

## general info

```bash
kubectl api-resources  # to show api
kubectl api-versions  # great to find information for manifests
```

## explain

```bash
kubectl explain deployment.spec.template.spec.containers.envFrom.configMapRef
```

## run a pod in iterative way

```bash
kubectl run -it --rm --restart=Never --image ubuntu podname
```


```bash
kubectl run -it --rm --restart=Never --image nicolaka/netshoot netshoot
```

### with a command to pass

```bash
kubectl run --image busybox --restart=Never pod-name -- sleep 36000
```

note:
- `-it` = short of `-i --tty`
- --rm delete the pod after it exits

## execute (= attach to a pod) a bash in a pod

```bash
kubectl exec -it dumb-server-9d7b889f9-6z284 -- bash
```



## set namespace in context

```bash
kubectl config set-context --current --namespace=NAMESPACE
```

## get event
### ordered by time

```bash
kubectl get events --sort-by=.metadata.creationTimestamp -w
```

### filter

Use the command `k get events --field-selector type!=Normal -A` to filter out the normal events and only give you warning- and information-type events.

## create manifest from kubectl

```bash
kubectl create deploy .... --dry-run=client -o yaml
```


## proxy

```bash
kubectl port-forward --namespace redis service/my-redis-master 6379:6379 > /dev/null
```
