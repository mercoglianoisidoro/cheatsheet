# System Updates

## Rolling Updates
*in short:* same number of instances, gradual update.

Gradual update and monitoring of each instance. No downtime needed.


## Blue-Green Deployments
*in short:* both versions installed, traffic redirected.

Blue is the current version, Green the next one. Both versions are installed but the traffic is only on the blue version. Once the green is installed, smoke test! If everything is ok, traffic is redirected to the green version. Then check monitoring. In case of problems, fallback to the blue. If everything is ok, remove the blue.


## Canary Releases
*in short:* both versions installed, traffic progressively redirected.

Both versions are installed and the traffic is progressively switched. Monitoring lets you continue or rollback.
